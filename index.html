shipfast.design

Paste a URL, get the site's design system back as clean HTML + CSS

A six-stage pipeline that extracts design tokens and components from any website with Playwright, regenerates them as framework-free code with an LLM, then verifies the output numerically against the original.

~140×cheaper per site: $7–8 agent run → ~$0.05
98–100%computed-style match on 9 of 10 reference sites
2×faster and ~50% cheaper with model thinking off
36–121 send-to-end per site
  • Replaced a free-running agent with deterministic token extraction plus small, parallel, text-only LLM calls (150–800 tokens per component) under a hard per-job budget cap.
  • A verifier renders each generated component offline and diffs computed styles; anything under 85% gets one repair call, then a deterministic fallback.
  • Hardened for untrusted input: SSRF guard, isolated Chromium per job, output sanitizer, sandboxed previews and page text replaced with placeholders to block prompt injection.
